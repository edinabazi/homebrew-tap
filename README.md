# Homebrew Tap

Homebrew casks for [Playhead](https://github.com/edinabazi/playhead) and
[Kompakt](https://github.com/edinabazi/Kompakt).

```bash
brew install --cask edinabazi/tap/playhead
brew install --cask edinabazi/tap/kompakt
```

The casks are updated automatically when a new release of either app is published.
